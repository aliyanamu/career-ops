# Japan Career Pivot — Plan & Decision Log

_Started: 2026-07-11. Living doc — update as reality changes._

## The decision, in one line

Move into Japan-based software engineering, using an existing East-Asian-language
head start (Korean at ~70% reading, basic Chinese/HSK1) to make Japanese a
realistic, high-leverage asset instead of a from-scratch grind.

## The reframe (most important thing on this page)

Two separate questions, not one:

1. **Do I want to live/travel in Japan?** → Lifestyle goal. If yes, Japanese is
   worth it regardless of the career math.
2. **Is Japanese a good SWE career investment?** → Depends on which door I use.

**Do NOT gate the career move on reaching N2.** There are two doors in; only one
needs JLPT.

| | Door A: English-first global tech | Door B: Domestic Japanese cos |
|---|---|---|
| Japanese | None → basic | N2 minimum |
| Who | Mercari, Rakuten, PayPay, LINE, SmartNews, foreign SaaS, startups | SIer/SES, mid-size local firms |
| Pay | ¥8–13.5M+ (¥30M+ at FAANG-JP) | ¥4–8M |
| Apply | **Now** | After ~1.5–2 yrs study |
| Volume | Fewer roles, high competition | Huge (what gittap.jp shows) |

**Strategy: chase Door A now, learn Japanese in parallel to unlock Door B +
daily life + HSP visa points.**

## My unfair advantage (why the ROI works for me specifically)

- Korean read at ~70% (light novels, 2 yrs casual). Korean↔Japanese is the
  closest major-language grammar pair — same SOV, particles, topic marker,
  honorifics. The hardest part (grammar intuition) is largely pre-paid.
- Sino-Korean vocabulary maps onto kanji readings. HSK1 Chinese seeds kanji shapes.
- Net effect: ~30–40% less time to N2 than a blank-slate learner.
  - N3: ~6–9 months real study
  - N2: ~18 months realistic

## Cons / risks (eyes open)

- **Pay ceiling.** Japan tech pays well below US/EU. Door A + FAANG-JP are the
  exceptions. Tokyo CoL is moderate so it nets okay for lifestyle, not for wealth.
- **JLPT ≠ speaking.** N2 gets hired + reads docs; conversational fluency is a
  separate on-the-ground grind (already know this from Korean).
- **Global SWE softness is real**, but Japan has less AI-junior displacement
  (language moat + slower adoption), and I'd carry a rare differentiator.
- English-only role supply is more cautious in 2026 than peak years — expect
  competition at Door A.

## Plan

### Track 1 — Career (start NOW, don't wait on Japanese)
- [ ] Build a "Japan-ready" CV (English). Lead with strongest specialization —
      cloud/AI/data roles keep English requirements loosest.
- [ ] Set up career-ops scanning for Japan English-first boards:
      tokyodev.com, japan-dev.com, gittap.jp, Mercari/Rakuten/PayPay/LINE careers.
- [ ] Apply to Door A roles as they appear (quality over quantity — see AGENTS.md ethics).
- [ ] Target specialization depth: "strong specialist + basic Japanese" beats
      "generalist + no Japanese."

### Track 2 — Japanese (start NOW, runs in parallel)
- [ ] Leverage Korean: learn hiragana/katakana first (fast), then kanji via
      Korean/Chinese hanja/hanzi knowledge.
- [ ] Milestone: N3 in ~6–9 months (reading-first, matching how Korean was learned).
- [ ] Milestone: N2 in ~18 months → unlocks Door B + HSP visa 10 pts.
- [ ] Speaking is a separate later track — don't let it block JLPT progress.

### Track 3 — Visa / logistics (research, low effort now)
- [ ] Engineer/Specialist in Humanities visa = standard path (CS degree or exp).
- [ ] HSP (Highly Skilled Professional) points-based fast-track to PR:
      70 pts → PR in 3 yrs, 80 pts → PR in 1 yr.
      JLPT N2 = +10 pts, N1 = +15 pts (not cumulative). Income ≥¥10M = max 40 pts.
      Income floor: below ¥3M disqualifies regardless of points.
- [ ] Recheck exact point thresholds before applying — rules shift.

## Decision checkpoints

- **Month 3:** Any Door A interviews? If zero, reassess CV/specialization angle.
- **Month 9:** N3 reached? If far behind, re-scope timeline (not abandon).
- **Month 18:** N2 + PR-points math. Decide Door B / long-term-Japan commitment.
